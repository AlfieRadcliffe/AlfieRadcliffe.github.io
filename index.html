A bit about me

I'm a Computer Science student at Newcastle University, now in second year after finishing first year with an average above 80%. I'm interested in two things that don't always meet: how software works under the hood, and how it feels to the person using it.

On the technical side, I'm building a real-time multiplayer game server in C to put my Networks module into practice, and next I'm writing a small operating system from scratch. Modules in Security Programming and Algorithms have pushed me to care about code that is safe and efficient, not just code that runs.

On the human side, I love human-computer interaction: why some interfaces feel effortless and others get in the way. I like design with personality, and I often reach for hand-drawn elements to give things character. This portfolio is a good example: a notebook built from scratch with no frameworks, starring a character I drew myself, but still quick to read.
